# Licensing notes

The release bundles third-party Crowsnest/uStreamer components.

The corresponding license files are shipped inside the payload:

```text
crowsnest/LICENSE
crowsnest/bin/ustreamer/LICENSE
```

Keep these files with the corresponding runtime when redistributing the release.

This documentation does not attempt to replace the legal text of those licenses. The authoritative license terms are the bundled license files themselves.

The project repository should add a top-level project license for QCM itself once the desired license is explicitly chosen by the project owner. No new QCM license is inferred by this documentation.
